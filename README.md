# EvoDesk · EvoFlow 式个人 AI 工作台

本地优先的个人工作台:任务收口 → AI 分诊路由 → 流程化执行(后续里程碑)→ 数据反哺流程进化。
设计文档见 `docs/superpowers/specs/`,实施计划见 `docs/superpowers/plans/`。

## 启动

```bash
npm install
npm run dev        # http://localhost:3000
```

数据存于 `data/evodesk.db`(SQLite,WAL)。首次启动自动建表并写入种子数据(示例任务/项目/周期规则/流程模板)。

## 测试

```bash
npm test           # vitest 单测 + API 集成测试
npm run build      # 生产构建
```

## 当前里程碑(M1–M5 全量)能力

- 收件箱:快速录入、AI 一键分诊(标签/复杂度/流程模板,失败自动降级)、确认就绪
- 任务看板:状态分列、项目过滤、手动流转(状态机保护)、卡片直达执行视图
- 仪表盘:核心数据、今日清单(延期置顶)、项目进度
- 周期任务:每日/工作日/每周规则,到点自动投放,错过补齐
- 设置:主题(深色默认+蓝紫强调)、成本预算、Obsidian vault 路径、待人工阈值
- 顶栏:实时时钟、每日语句、全局快速新增
- 任务执行:流程实例逐步推进(LLM 流式产出、脚本步骤安全门+输出留痕、人工步骤、
  checkpoint 通过/打回、失败兜底:重试/人工接管/跳过、运行取消、评审打分)
- AI 对话台:多会话、会话内按消息切换模型、流式回复、每条消息的模型与成本记录、
  结论一键转任务
- 模型路由:供应商档案一键导入(指向 Claude Code 启动器配置目录,坏配置自动跳过、
  密钥仅存本地)、按档位派生执行器(opus→规划/sonnet→执行/haiku→分诊)、连通性测试
- 流程库:模板统计徽章(成功率/成本/满意度)、谱系与状态、克隆/退役、
  进化事件时间线;复盘分析生成实验变体(experimental)→ 人工审阅 diff → 晋升
- 快捷指令:仪表盘一键执行命令(安全门:渲染预览+风险告警+白名单)/打开网页/
  启动 Claude Code 终端(选择供应商档案与档位模型,DryRun 预览)
- 笔记速记:灵感卡片流、一键转任务、一键存入 Obsidian(02_笔记 子目录)
- 知识库:Obsidian vault 白名单浏览/Markdown 搜索/在线编辑保存
- 风险雷达:已延期/待人工超时/成本预算/低绩效模板四类风险自动汇总
- 日历:月视图展示任务截止分布,按日查看与快速新增
- 统计:完成趋势/成本趋势/模板绩效对比图表(recharts)
- 移动端:抽屉导航 + 底部高频导航,响应式适配
- 时区:「今天」边界按设置时区计算(留空跟随系统)

## 接入 AI(推荐路径)

1. 「执行器」页 → 供应商档案 → 填入你的 Claude Code 启动器配置目录(含 *.txt,
   如 D:\AI\setting\发布包)→ 扫描导入(坏配置自动跳过;密钥仅存本地,界面掩码显示)
2. 按档位派生执行器:opus→规划、sonnet→执行、haiku→分诊(默认禁用)
3. 在列表中「启用」需要的执行器,点「测试」验证连通性
4. 也可手动「+ 新增」执行器(名称/角色/模型/API 地址/密钥必填)

未配置模型时分诊自动降级为默认建议,对话台给出配置引导;配置后仪表盘、
收件箱分诊、任务执行、对话台全部可用。种子执行器(快速/强模型)也可通过
环境变量 EVODESK_FAST_KEY / EVODESK_STRONG_KEY 启用。
