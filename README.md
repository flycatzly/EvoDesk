# EvoDesk · EvoFlow 式个人 AI 工作台

> 本地优先的个人"数字驾驶舱"——把分散的任务、笔记、资讯、日程收口到一处,
> 由 AI 按复杂度智能分诊、流程化执行,并用执行数据反哺流程进化,**越用越顺手**。

EvoDesk 借鉴 EvoFlow(arXiv:2502.07373)的进化式多智能体思想:任务不是简单的待办列表,
而是经过 **收件箱捕获 → AI 分诊(标签 × 复杂度)→ 路由到流程模板 → 异构执行器(AI / 脚本 / 人工)
逐步处理 → 评审打分 → 数据反哺流程进化** 的完整链路。所有数据存于本地单个 SQLite 文件,
无云端依赖;AI 不可用时整体降级为手动模式,依然可用。

## 🚀 快速启动

```bash
# 1. 安装依赖(要求 Node.js ≥ 20)
npm install

# 2. 启动开发服务器
npm run dev
# → 打开 http://localhost:3000
```

首次启动自动建库(`data/evodesk.db`,SQLite + WAL)并写入种子数据:
4 条流程模板(S 轻量 / M 标准 / L 深度 / 资讯摘要)、执行器、示例项目与任务、
周期规则(每日英语 / 每周健身)、示例笔记与快捷指令——打开即用。

**生产模式**(可选):

```bash
npm run build
npm run start
```

**生产数据库备份**:直接复制 `data/evodesk.db` 即可(WAL 模式下建议连同 `-wal`/`-shm` 一起拷)。

## 🧭 五分钟上手

1. **捕获**:顶部快速新增,或在「收件箱」一句话记录(支持 `POST /api/tasks` 外部投递)
2. **分诊**:收件箱点「一键分诊」→ AI 建议标签 / 复杂度 / 流程模板(S 琐事快跑、M 常规、L 深度)→ 确认就绪
3. **执行**:从看板或卡片进入执行视图,流程逐步推进——LLM 流式产出、脚本步骤确认后执行、
   人工步骤填写、checkpoint 审核通过或打回;失败可重试 / 人工接管 / 跳过
4. **评审**:完成后打分(1–5)+ 备注,数据自动汇入模板绩效
5. **进化**:流程库中触发「复盘分析」,AI 生成改进变体(实验状态)→ 审阅 diff → 晋升取代旧版
6. **回顾**:仪表盘看今日清单与风险雷达;日历看截止分布;统计页看趋势与模板绩效

没配置 AI?一切照常可用——分诊自动降级为默认建议,脚本 / 人工步骤不受影响。

## ✨ 功能全景(M1–M9 全量)

### 任务与执行
- **收件箱**:快速录入、AI 一键分诊(失败自动降级)、确认就绪;周期任务到点自动投放,错过补齐
- **任务看板**:状态分列、项目过滤、手动流转(状态机保护)、卡片直达执行视图
- **任务执行**:流程实例逐步推进——LLM 流式产出、脚本步骤安全门(渲染预览 + 风险告警 +
  目录白名单)、人工步骤、checkpoint 通过 / 打回、失败兜底(重试 / 人工接管 / 跳过)、
  运行取消、评审打分;进程中断自愈
- **项目维度**:任务挂项目、看板按项目过滤、仪表盘项目进度条

### AI 能力
- **AI 对话台**:多会话、会话内按消息切换模型、流式回复、每条消息记录模型与成本、结论一键转任务
- **模型路由**:供应商档案一键导入(指向 Claude Code 启动器配置目录,坏配置自动跳过,
  密钥仅存本地且界面掩码)、按档位派生执行器(opus→规划 / sonnet→执行 / haiku→分诊)、连通性测试
- **流程进化**:复盘分析生成实验变体 → 人工审阅 diff → 晋升(同谱系旧版自动退役)/ 淘汰,全程事件留痕

### 操作本地电脑(安全模型:确认门 + 白名单 + 全量留痕)
- **快捷指令**:仪表盘一键执行命令(预览 + 风险告警)/ 打开网页 / 启动 Claude Code 终端
  (选档案与档位模型,DryRun 预览,临时密钥文件即用即删)
- **脚本步骤**:流程内执行 PowerShell / cmd / bash / python,超时终止、输出留痕 64KB、
  破坏性命令启发式告警

### 信息管理
- **笔记速记**:灵感卡片流、一键转任务、一键存入 Obsidian(`02_笔记` 子目录)
- **知识库**:Obsidian vault 白名单浏览(默认 `D:\work\Obsidian\Obsidian`,可在设置修改)、
  Markdown 搜索、在线编辑保存
- **日历**:月视图展示任务截止分布,按日查看与快速新增

### 驾驶舱与画布工作台(M6 重构)
- **拖拽画布首页**:组件化信息聚合页——指标卡 / 待办勾选 / 迷你日历 / 笔记灵感 /
  常用链接 / 目标进度 / 知识库概览 / 风险雷达 / 快捷指令,九类组件自由组合
- **编辑与锁定**:「编辑布局」拖动组件与分组、跨组移动、2/3 栏切换、增删分组组件;
  「锁定布局」防误拖;多工作台切换,内置学生 / 职场开发者 / 生活三套模板一键套用
- **只读分享**:一键生成 `/share/<token>` 只读链接,可随时吊销
- **常用链接页 / 目标进度页**:分类管理、行内编辑、目标步进打卡与归档;
  链接页支持关键字搜索(名称/链接/分类)、分类折叠与筛选、分类一键重命名;
  首页链接组件限量展示(每类前几条 + 总数入口),整库书签导入也不会撑爆首页;
  书签导入自动剔除浏览器内部目录名(书签栏/其他书签/收藏夹等不当分类)
- **本周复盘**:完成率(完成 /(完成+本周截止未完成))、每日完成柱状、本周新增任务/灵感
- **新手帮助页**:五步上手、模块一览、人群模板组合、最佳实践与避坑、FAQ
- **风险雷达**(保留):已延期 / 待人工超时 / 成本预算 / 低绩效模板四类自动汇总
- **顶栏**:实时时钟、每日语句、全局快速新增;移动端抽屉 + 底部导航;时区可设

### AI 增强(M8)
- **需求教练**(/coach):不写代码的教练式对话——逐轮只问一个问题(场景→痛点→模块→数据→风格→验收,
  最多 6 轮),信息足够后输出结构化「最终搭建提示词」,一键复制 / 存为笔记;复用对话台模型配置
- **本地 Skill 地图**(/skills):一键扫描本地 Skill 目录(默认 `~/.agents/skills` 与 `~/.claude/skills`,可改),
  解析 SKILL.md 汇总名称/描述、按目录分类,搜索、星标与用法备注(存本地库);只读扫描,不执行任何 skill
- **对话台会话管理**:多会话切换/新建/重命名/删除;**会话绑定本地工作目录**(绝对路径,服务端校验存在性),
  目录上下文自动注入对话,让 AI 知道在哪个项目里工作

### 求职雷达(M9)
- **BOSS直聘抓取**(/jobs):托管 `scripts/boss_cdp_raw.py`——Chrome DevTools Protocol + 隔离 profile
  (`~/.boss-zhipin-scraper/chrome-profile`,不碰主浏览器),页面内 XHR 同步调用搜索接口,提取明文薪资
- 关键词/城市/页数(≤10)/只抓列表等参数;「启动 Chrome → 登录 → 连通自检 → 抓取」四步引导;
  按 job_id 去重入库、结果筛选搜索、JD 查看、**CSV 导出(UTF-8 BOM)**、运行记录留痕
- 守门内置:单次 ≤10 页、页间随机 12-22s 延迟、仅限个人求职研究;接口按文档实现未对线上验证,请先自检

### 主题与数据安全(M7)
- **7 套主题**:粉色 Ins / 薄荷清新 / 奶油手账 / 蓝白学习 / 极简效率 / xfc(白纸橙强调灰绿辅助)/
  深色科技(默认),顶栏色板下拉即时切换,低饱和配色,首屏无闪变
- **一键导出 / 导入**:JSON 全量备份(默认剥离 API 密钥,可显式包含),导入前强制自动快照,
  zod 校验失败不落库;换电脑迁移 = 导出 → 新机导入
- **快照备份 / 恢复**:better-sqlite3 backup API 生成 `data/backups/*.db`,保留最近 20 份,
  恢复前自动再做快照

## 🔑 接入 AI(推荐路径)

1. 「执行器」页 → 供应商档案 → 填入你的 Claude Code 启动器配置目录(含 `*.txt`,
   如 `D:\AI\setting\发布包`)→ **扫描导入**(坏配置自动跳过;密钥仅存本地,界面掩码显示)
2. 按档位派生执行器:opus→规划、sonnet→执行、haiku→分诊(默认禁用)
3. 列表中「启用」需要的执行器,点「测试」验证连通性
4. 也可手动「+ 新增」执行器(名称 / 角色 / 模型 / API 地址 / 密钥必填)

未配置模型时分诊自动降级为默认建议,对话台给出配置引导;配置后分诊、任务执行、
对话台全部可用。种子执行器也可通过环境变量 `EVODESK_FAST_KEY` / `EVODESK_STRONG_KEY` 启用。
支持 OpenAI 兼容与 Anthropic 兼容双协议端点(Z.ai / DeepSeek / MiMo / Ollama 等均适用)。

## 🔒 安全与隐私

- 所有数据(含 API 密钥)仅存本机;密钥界面掩码、日志不打印
- 脚本 / 命令执行默认需人工确认,AI 生成命令强制过目;工作目录白名单;执行全量留痕
- 导入的供应商档案中的 hooks / mcpServers 等段落**不会被执行**,仅原样透传给 Claude Code 启动
